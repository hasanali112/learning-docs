# এই সাইট সম্পর্কে

শেখার সময় সবকিছু মনে থাকে, কিন্তু কয়েক সপ্তাহ পর অনেক কিছু ভুলে যাই। তাই যা শিখি, এখানে নিজের ভাষায় লিখে রাখি।

## কী কী থাকবে

- **Python:** ভেতরে কীভাবে চলে, bytecode, memory
- **FastAPI:** setup থেকে শুরু করে request এর পুরো যাত্রা
- **System Design:** design pattern, scalability, database
- আর যা কিছু নতুন শিখবো

## কীভাবে পড়বো

বাম পাশের মেনু থেকে বিষয় বেছে নাও। ডান পাশে **এই পেজে** অংশে পেজের সব শিরোনাম থাকে, ক্লিক করলে সরাসরি সেখানে চলে যাবে। উপরের **খুঁজুন** দিয়ে যেকোনো শব্দ খোঁজা যায়।

::: tip মনে রাখার কৌশল
শুধু পড়ে রাখলে ভুলে যাওয়া সহজ। প্রতিটা নোটে নিজের একটা উদাহরণ লিখে রাখো, পরে সেটাই সবচেয়ে বেশি কাজে দেয়।
:::
